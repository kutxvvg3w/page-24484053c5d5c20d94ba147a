品牌简介

疯兔加速(FengTuYun)面向需要稳定跨境访问与低延迟转发的用户，提供可订阅的机场节点与多端客户端。本页说明套餐容量、适用场景、配置步骤与官方下载入口，便于自行完成订阅导入与日常加速。

服务侧重线路可用性、流媒体解锁与游戏转发优化。用户可按流量与同时在线设备数量选择基础版、旗舰版或团队版，年付可降低月均成本。

使用场景

远程办公与资料同步

访问海外协作平台、代码仓库与云盘时，通过订阅节点降低超时与中断，适合固定工位与差旅切换网络。

流媒体与内容研究

基础版覆盖常见内容库；旗舰版强调全节点原生解锁，减少地区限制导致的播放失败。

游戏与实时语音

旗舰版包含 IPLC 专线游戏加速优化，用于降低抖动；团队版提供更高带宽节点，适合多人同时在线。

小团队统一出口

团队版支持 20 台设备与企业定制路由，便于把不同应用分流到指定线路。

配置流程（重点）

疯兔加速(FengTuYun)的核心路径是：选择套餐 → 获取订阅链接 → 安装客户端 → 导入订阅 → 选择节点并开启系统代理或 Tun 模式。以下按左右交错说明各步。

1. 确认设备与流量

先统计同时在线终端数量与月用量。浏览与办公可从基础版起步；需要原生解锁与游戏线路再升至旗舰版；多成员共用选择团队版。

2. 获取机场订阅

在账户页复制 Clash / Sing-box / Surge 通用订阅地址。请仅保存在本机密码管理器，不要发到公开群组。订阅更新周期建议 24 小时内至少刷新一次。

3. 安装对应客户端

Windows 与 macOS 可用图形客户端；Android 建议支持订阅的代理应用；iOS 需在系统允许的客户端中粘贴订阅。官方下载入口见下方锚点。

4. 导入并测速

导入后先更新节点列表，对常用地区做延迟测试，再开启规则分流：国内直连、海外走代理。游戏可单独指定 IPLC 节点。

5. 日常维护

流量接近套餐上限时提前升级。更换网络后若无法连通，先关闭再开启 Tun，或切换备用节点。团队版可将域名与端口策略交给客户经理协助固化。

常见问题 FAQ

疯兔加速(FengTuYun)是什么？和普通加速器有何不同？

它是可订阅的机场服务，提供节点池与多端客户端导入方式。与单一线路加速器相比，可按规则分流、更换节点，并按流量与设备数计费。

如何完成第一次配置？

选择套餐后复制订阅链接，安装对应客户端，导入并更新节点，再开启系统代理或 Tun。详细步骤见本页「配置流程」。

基础版、旗舰版、团队版该怎么选？

个人轻度使用选基础版（100GB / 3 设备）。需要原生流媒体与游戏专线选旗舰版。多人共用、需要定制路由选团队版。

客户端在哪里下载？是否必须用官网？

应使用官网提供的客户端说明与下载入口，避免来路不明的安装包。本页「客户端下载」章节给出各系统导入要点。

节点连不上或速度波动怎么办？

先更新订阅，更换同区域其他节点，检查本地防火墙与系统时间。游戏场景优先使用标注 IPLC 的线路。持续失败可提交工单，旗舰版与团队版享有更高优先级。

年付如何计算？流量是否跨月累积？

年付金额已在各套餐标明。流量按自然月重置，不跨月累积。设备同时在线数按套餐上限执行。
